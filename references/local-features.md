# 局部优化候选

供比较的设计动作，不是固定参数配方。只采用与当前缺陷相关的项；新增候选没有证据时标为待验证。

| 目标问题 | 可考虑的动作 | 需要核对 |
|---|---|---|
| 方向改变可减少关键面悬空，或整件难以兼顾各部位 | 比较摆放方向、拆件与定位连接结构 | 用户指定外观面、接缝位置、装配方法和整体尺寸；更少支撑不自动等于最佳方案 |
| 配合过紧/过松或入口难装 | 参数化孔轴间隙、止口、入口倒角和局部避让；按 [装配公差闭环](fit-and-tolerance.md) 校准 | 分别测量配合双方，区分半径/直径间隙与单边/总间隙、首层局部与整体偏差；不固定通用公差 |
| 需要吸收尺寸波动或减少装配松动，且允许结构退让 | 比较薄壁、释放槽、局部弹片或斜齿阵列，按 [弹性配合检查](fit-and-tolerance.md) 验收 | 刚性定位与弹性预紧分工、最松/最紧组合、薄槽实际路径、持续预紧及拆装寿命；不默认提高尺寸精度 |
| 局部强度不足或薄弱截面不适合受力 | 比较打印方向、壁厚、加强肋、圆角和连接截面 | 真实受力方向、空间及配合约束；几何检查不能代替负载验证 |
| 卡臂折断、难压入或容易拔出 | 按 [弹性卡扣](snap-fit-design.md) 联合设计方向、根部、卡头与插座 | 分开回弹、插入力、保持力和旋转阻力，核对槽底及循环/持续扣合 |
| 倾斜打印接地窄、支撑滑脱或连接齿提前断开 | 按 [建模支撑鳍片](modeled-support-fins.md) 分开设计本体稳定、底座与牺牲连接 | 打印坐标中的水平连接、逐层连续路径、附着及拆除残痕 |
| 拿取、握持、装拆时触手棱边尖硬，或小倒角仍不够圆润 | 优先比较连续圆角；按实际打印方向把触手自由边、贴床边与功能边分区 | 倒角斜面两侧仍有折线；保护剩余壁厚、配合面和贴床起线；半径不固定，触感需实物确认 |
| 圆盘或台阶底部悬空 | 不同高度圆环、弧段或短肋托住关键轮廓 | 剩余跨距、第一条悬空线、闭环取出路径 |
| 支撑粘连、难施力拆除 | 顶部收窄、局部接触、断开槽、分段或抓取位置 | 支撑刚度、打印碰撞、拆除力是否损伤成品 |
| 小孔要求不加支撑或支撑难以取出 | 按 [小孔禁支撑交接](#小孔免支撑与禁支撑交接) 比较方向、自承孔顶与局部支撑屏蔽 | 保留功能孔径/装配包络，逐孔检查支撑侵入及模型桥接，孔外必要支撑分别处理 |
| 水平孔顶起线不稳定 | 比较孔顶斜面/泪滴轮廓、桥接台阶或可去除薄膜 | 通孔净空、装配包络、后处理可达性及薄膜实际路径 |
| 侧孔下垂或装配沿层纹开裂 | 按 [侧孔设计](side-hole-design.md) 比较朝向、孔顶让位、释放、局部壁线与孔侧弹片 | 区分悬空质量与压入受力，保护孔功能；微特征不保证增强或自动保留 |
| 大面积平面悬空或架空顶板 | 按 [平面悬空处理](large-flat-overhangs.md) 比较方向、拆件、自承结构及支撑 | 首条路径两端是否有锚点、有效跨距、底面要求及支撑取出空间；只托边缘未必托住内部 |
| 面向平台的圆角形成陡峭悬空 | 局部倒角、斜面过渡或调整圆角起点 | 外观、配合变化；说明角度相对水平面还是竖直面 |
| 小孔、刻字或细壁在切片中消失 | 在允许范围内加宽/加深、改方向或改截面 | 实际路径、笔画间距、强度与比例，不能只按喷嘴直径推断 |
| 接地细节或装配入口受首层影响 | 入口倒角、底边退让或可去除耳片 | 配合面、底面附着及拆除痕迹；区分几何和切片补偿 |

## 小孔免支撑与禁支撑交接

小孔的免支撑设计目标与用户的禁支撑约束分别记录；后者一旦明确就不能被自动支撑默认值覆盖。不要把一次软件观察推广成任意材料/方向/孔径都能桥接的结论，也不指定通用“小孔直径上限”。

- 在用户允许的范围内比较打印方向、保留完整配合包络的孔顶斜面/泪滴过渡或桥接台阶。精密配合孔不得任意改径、填孔或变形；若需要牺牲薄膜，应先确认可接受的后处理，不能把它当作无需去除的免支撑几何。
- 螺孔、沉孔及对应螺母装入槽、工具通道一起交接禁支撑范围；孔外必要支撑单独保留。仅需改局部支撑设置时不重建CAD，也不关闭整件支撑掩盖孔内问题。
- 切片侧应保存/回读屏蔽设置并实际重切，检查全孔深、孔口以及支撑接口层；程序检查计入线宽、层厚与打印变换。短屏蔽体不一定阻止从上方生成的支撑经过孔腔，应依据实际路径调整范围。核验以真实孔腔为界，避免把扩大的屏蔽体或刀具延伸到外部空气的部分当成孔内。
- 孔内无支撑与孔顶可制造分别验收：第一条模型路径的起点、两端锚固和有效跨距必须核对。无实际切片时标明待验证；孔径、桥接表面与装配仍需实物。无法在当前保护范围满足时，交回具体高度/路径问题，不静默恢复孔内支撑。

本节规定设计与验收方法，不提供通用桥接参数或已验证的打印质量保证，也未新增通用3MF编辑器。

## 触手圆角与贴床边分区

目标是圆润触感时，优先处理真实几何的连续圆弧及角点过渡；倒角适合打断锐边、入口引导或某些底边打印约束，但不能仅凭“已倒角”认定握持舒适。不要把所有边统一圆角，也不要用平滑着色替代实体处理。

- 先用零件到排盘的变换定位贴床面。装配里的上/下不等于打印里的上/下；侧放件两侧的相同外形边可能需要不同处理。
- 自由触手边可圆角；贴床或朝下的圆角可能产生较陡悬垂，比较小倒角、延后圆角起点或换向。功能接触面、孔窝、定位面及局部薄肉按保护范围处理，必要边界说明为何保留。
- 回读实际STL/3MF，分别采样圆弧、倒角及其交汇/收尾；检测网格退化与原配合尺寸。圆弧分段数按离散误差和尺寸选，不把“多段”自动视为合格。切片路径、首层及真实手感另验证。

### P002：桌夹触手边从小倒角改圆角

- 来源：维护者桌夹项目 MDL-028，2026-10-31 的几何审查与反馈摘要；原始模型、检查脚本和私有记录未随仓库分发，公开读者暂无法独立复跑。用户说主体直接倒角仍“感觉尖尖的”，同意 R1 圆角方案；没有说明已打印，故不记作实打触感或伤害反馈。
- 对象/保护区：R1绿色夹体；上夹板5mm、中夹板7mm、下连接座7mm、挂杆8mm、孔窝及接触面保持。其余5类零件与S1文件身份保持。
- 方向/动作：夹体侧放，原X+12为贴床面、X−12为自由侧。指定触手自由边采用半径1mm、12段圆弧；贴床边保留0.6mm45°倒角，内侧长圆棱在过渡筋前1mm收尾。这些是该模型参数，不是通用推荐值。
- 网格实测：独立回读STL与装配3MF，64条代表截面验证圆弧/贴床倒角/收尾，原尺寸及网格拓扑通过；21桌厚、84四向、180个2°转角和装入/操作代理重跑通过。记录只支持覆盖的几何检查，不是全局无缺陷或承载证明。
- 切片/实打：本版未切片或实打，材料、喷嘴、层高、线宽未确认。是否真正更舒适、底边打印质量及强度仍待验证。
- 实现边界：使用该项目的建模脚本和独立回读检查；选择性的圆角/倒角依赖当前坐标及保护区，未封装成通用全边处理工具。本仓库仅收录设计方法与历史结果摘要。

工艺背景：[Prusa面向打印的建模说明](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)说明朝平台圆角的悬垂问题；分区选择和本案例参数仍需结合实际模型判断。

## 参数表达与验证

常用参数：目标底面高度 `z_target`、顶面高度 `z_support`、几何间隙 `gap_z = z_target - z_support`、顶宽、底宽、XY 分离距离与分段位置。

薄膜、薄顶或牺牲连接，要分别记录几何厚度与切片实际层数/线数。不要仅由“厚度 ÷ 名义层高”推定路径；首层、可变层高、补偿、薄壁处理和层面取样可能改变结果。

- 几何验证：保护区是否受影响，间隙是否存在，支撑能否制造和取出，可触及锐边的圆角/倒角是否保留且未产生新的薄尖边？
- 切片验证：关键路径是否存在，第一条悬空线怎样形成，预期薄弱连接是否保留？
- 实打验证：是否托住、可拆、损伤成品，接触面质量是否达标？

可以只完成部分验证，明确范围即可。没有切片器时交付参数化模型与待查关键层，不虚构结果。
