## 实测几何

圆环是多边形离散网格，直径采用顶点圆拟合近似值，单位 mm。

| 参数 | 外环 | 内环 |
|---|---:|---:|
| 底部 Z | 0 | 0 |
| 顶部 Z / 高度 | 14.65 | 20.80 |
| 对应模型底面 Z | 14.85 | 21.00 |
| 竖向几何间隙 | 0.20 | 0.20 |
| 底部外径 | 70.386 | 53.283 |
| 底部内径 | 65.386 | 49.283 |
| 底部径向壁厚 | 2.50 | 2.00 |
| 顶部径向壁厚 | 2.50 | 约 0.475 |

外环等厚直壁；内环两侧逐渐向中间收拢，剖面下宽上窄。两环与本体在网格拓扑上分离，未发现专门分段的拆除槽；不要描述成作者已经设计了断开槽或拉手。

## 可迁移的思路与证据边界

- 按悬空面高度分级承托，避免填满整个下方空间。
- 沿圆周配置支承，对应圆盘轮廓；其他形状需重新选支承线。
- 内环具有宽底窄顶。改善稳定性、减小接触/粘连是机理推断；用户确认总体打印效果不错，但未分别评价这些作用。
- 两处预留 0.20 mm 几何间隙。兼顾承托与拆除是合理解释，不能断言所有材料适用或底面不受影响。

热挤出线条可能下垂、跨越或局部接触下方支撑，取决于实际路径和工艺。几何间隙不保证打印后仍是规则空气层，也不保证切片后恰好空一层。
