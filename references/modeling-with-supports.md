# 示例：在建模阶段设计手工支撑

**性质：假设设计演练。没有生成 CAD/STL、执行切片或进行实打。** 本例展示如何组织决策与输出；尺寸仅用于描述场景，不是推荐打印参数。

## 输入与保护范围

设计一个开底壳体：内部顶板悬空区域 X 向 100 mm、Y 向 80 mm，顶板底面 z=30 mm、厚 3 mm，四周壁向上生长。方向固定，顶板需保持一体，内底面须平整，不能用永久肋侵占净空。底部开放，可作为拆除入口。材料、喷嘴、层高、线宽与表面验收标准未知。

这组约束排除了倒置打印、拆出顶板和永久斜面，剩下切片器原生支撑与建模可拆支撑可比较。不能因为用户提到“手工支撑”就预先认定它效果更好。

## 在细化模型前怎样选方案

| 候选 | 在本例中的设计动作 | 尚需核对 |
|---|---|---|
| 切片器原生支撑 | 保留主体几何，利用开底空间布置可去除支撑 | 实际接口覆盖、首条悬空路径、接触和拆除结果 |
| 分段建模托条 | 主体与托条独立建模，底座稳定，分段后分别从底部退出 | 条间跨距、托条自身稳定、顶宽实际路径和拆除受力 |
| 较连续的建模托面 | 条间下垂不能满足要求时，比较增加托面覆盖 | 托面自身第一层怎样形成、粘连面积、整片或分段退出 |

若首层路径沿 Y 向跨接，沿 X 向分布的托条是一个待验证候选。实际首层轮廓可能沿另一方向，因此必须看路径后决定布置；有 Z 间隙的托条也不能简单算成把桥接可靠切成若干小跨距。

## 主体与支撑的参数关系

| 参数 | 表达 | 依据 |
|---|---|---|
| 目标底面高度 | `z_target = 30 mm` | 本例假设 |
| 竖向几何间隙 | `gap_z` | 待实际工艺与试片确定 |
| 支撑最高处 | `z_support = z_target - gap_z` | 参数依赖，随主体更新 |
| 顶宽、底宽、托条间距 | 独立参数，受稳定与路径约束 | 待比较，不套固定值 |
| 侧向避让、分段位置 | 与主体及拆除工具空间关联 | 须核对几何和退出方向 |

主体属于成品；托条属于打印后去除的几何。导出时保留共同坐标与间隙，不把托条分别落床而改变接触位置。普通模型实体不会因命名为“support”就自动获得切片器的支撑接口策略。

## 交付与验收示例

若任务已授权且建模工具可用，交付可编辑源、实际导出的主体/支撑部件、参数说明，以及关键接触区剖面。读取导出文件验证间隙、保护面、主体尺寸和部件相对位置。只做出方案时，应明确写“已完成参数方案，未生成模型文件”。

交给切片验证的重点是支撑最后几层、顶板首次出现层和后续层：薄顶是否保留、首线是否有落点、托条是否连续、自动支撑是否误填分离间隙。不要用 `gap_z / 层高` 直接宣布空了几层。

试片保留真实跨度、锚点、接触关系和局部拆除条件，可以沿非跨接方向缩窄，不能整体等比缩小。局部成功后仍需验证整面热变形和整件拆除；记录底面质量、支撑稳定、拆除难度和成品损伤。

如果后续加上底盖把腔体封住，原拆除方案即需重新评估；有间隙并不能解决支撑取不出来的问题。

## 本例的结论边界

已完成的是设计推演与参数关系说明。尚未完成几何测量、路径验证和实打，不能称为“可直接打印的可靠方案”。实际工作按 [平面悬空处理](large-flat-overhangs.md) 和 [建模与切片交接](slicing-handoff.md) 继续。
