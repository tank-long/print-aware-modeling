# Print-Aware Modeling

**在建模时就考虑 FDM 3D 打印，也检查和优化已有模型。**

[English overview](README.en.md) · [技能入口](SKILL.md) · [贡献案例](CONTRIBUTING.md)

这个 Agent Skill 帮助 AI 把用途、尺寸、装配和打印条件放在同一个设计流程里：从需求或草图开始建模，比较打印方向、结构与拆件方式，必要时设计手工支撑，再明确哪些结果已验证、哪些仍需要切片或实打。

首版为知识与工作流程型 skill。实际读取、修改和导出 CAD/STL 需要宿主提供可用的建模或网格工具。仓库没有内置 CAD 引擎、自动切片器或打印控制程序；仅发布建模 skill，可以独立使用。

## 适合用在哪里

| 场景 | skill 引导 AI 做什么 |
|---|---|
| 从想法或草图设计零件 | 明确尺寸依据、保护接口、受力和打印方向，再细化参数与结构 |
| 在建模时设计手工支撑 | 比较是否需要支撑，设计承托位置、接触关系、稳定底座和拆除路径 |
| 检查已有 CAD/STL | 检查悬空、桥接、薄壁、孔顶、配合、可触及锐边及方向相关风险 |
| 修正打印或装配问题 | 保护原有功能面，区分几何问题与工艺问题，并规划代表性试片 |
| 积累打印经验 | 分开记录几何实测、切片观察、实打反馈和机理推断，保留失败条件 |

“手工支撑”指在 CAD 或网格中显式建出的可去除几何，也可称为建模支撑、手绘支撑。它与切片器生成的原生支撑可能采用不同路径；留出几何间隙并不自动保证易拆或底面光滑。

## 安装与开始使用

在支持 `$skill-installer` 的 Codex 环境中，可以直接说：

```text
$skill-installer 从 https://github.com/tank-long/print-aware-modeling
安装仓库根目录的 skill，名称使用 print-aware-modeling。
```

也可以将仓库克隆到个人技能目录（已有同名目录时先合并，勿覆盖）：

```sh
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/tank-long/print-aware-modeling.git "$HOME/.agents/skills/print-aware-modeling"
```

然后在任务中调用 `$print-aware-modeling`。Codex 的发现目录和调用方式见 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)；未出现时重启宿主。其他支持 `SKILL.md` 的 Agent 可按其文档安装，但本项目尚未逐一验证兼容性。

### 从需求开始建模

```text
使用 $print-aware-modeling 设计一个桌边收纳盒。
桌板厚度实测为 25 mm，盒体外包络不超过 100 × 60 × 80 mm。
先比较结构、装配和打印方向，再建模；需要手工支撑时说明托哪里、怎么拆。
未提供的尺寸和工艺条件请标明假设或未知。
```

### 检查已有模型

```text
使用 $print-aware-modeling 检查这个 STL 是否适合 FDM 打印。
先检查单位、打印方向、悬空、薄壁和支撑拆除空间；此轮只分析。
孔位和配合面不能改变，分别说明几何结论与仍需切片、实打确认的内容。
```

### 建模阶段加入必要的可拆支撑

```text
使用 $print-aware-modeling 优化这个壳体的架空顶板。
打印方向固定，顶板不能拆件，内部净空不允许增加永久加强肋。
比较切片器支撑和建模可拆支撑；采用后者时，保留主体与支撑独立部件、
共享坐标，并参数化接触间隙和拆除通道。只报告实际完成的验证。
```

有切片软件可以继续检查实际路径；没有时，先完成几何和验证交接。无需安装另一个 skill。

## 输出应该是什么样

围绕当前任务，给出问题位置或设计目标、实际生成的文件或方案、关键参数及依据、方案取舍、验证状态与待确认条件。只有读取过截图时，不声称已完成网格测量；只有输出方案时，不声称已生成模型。

| 证据 | 能支持的结论 | 不能代替 |
|---|---|---|
| 几何 / 网格实测 | 在所查版本、方向和区域内的尺寸及几何关系 | 实际挤出路径、装配手感或承载 |
| 切片观察 | 实际生成的层和路径、间隙表现及薄特征是否保留 | 实物强度、拆除效果或表面质量 |
| 实打反馈 | 所记录样件及条件下的实际结果 | 所有材料、设备、尺寸和方向下的保证 |
| 机理推断 | 候选方案及验证理由 | 已成功打印的证据 |

## 范围与持续迭代

当前面向 FDM/FFF。树脂工艺、完整切片配置、模型平台发布和打印机控制不在本仓库范围内。尺寸、支撑间隙与悬垂角度均按具体条件判断，不提供一个数值通用的成功承诺。

安装 skill 不会启动后台学习，也不会自动上传模型或提交案例。它会在任务中寻找可复用经验，在当前用户授权范围内维护记录。贡献方式见 [CONTRIBUTING.md](CONTRIBUTING.md)，版本变化见 [CHANGELOG.md](CHANGELOG.md)。维护者可运行 `python3 tools/validate.py` 检查发布结构和本地引用；这不验证实际打印效果。
